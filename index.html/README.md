# Meus Sites Favoritos

Projeto desenvolvido para a atividade da disciplina de Desenvolvimento Web.

## Objetivo

Criar uma página HTML contendo:

- Título da página;
- Nome do aluno;
- 5 sites favoritos;
- Imagens dos sites;
- Links de acesso para cada site.

## Tecnologias Utilizadas

- HTML5
- CSS3
- Visual Studio Code
- GitHub

## Sites Utilizados

- YouTube
- Google
- GitHub
- Netflix
- Spotify

## Estrutura do Projeto

meus-sites-favoritos/

- index.html
- README.md

## Como Executar

1. Baixe o projeto;
2. Abra a pasta no VS Code;
3. Execute o arquivo index.html no navegador.
